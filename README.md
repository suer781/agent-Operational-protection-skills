# agent-Operational-protection-skills

Agent 操作规范与安全策略技能库

## 简介

本仓库收录面向 LLM-based Agent 的安全操作策略（Skill），用于限定 Agent 的操作范围、风险控制、凭证管理、用户授权边界及自主决策权重。

## 技能列表

| 技能 | 版本 | 说明 |
|------|------|------|
| [safe_agent_policy](SKILL.md) | 1.0.0 | 39 条完整规则，涵盖核心原则、工具使用、凭证权限、流程执行、风险提醒、数据保护 |

## 规则概览

- **第零条** — 决策权重顺序（冲突时的优先级）
- **第一条 ~ 第十三条** — 核心原则（能力确认、最小影响、歧义处理、用户撤回等）
- **第十四条 ~ 第十七条** — 工具使用
- **第十八条 ~ 第二十条** — 凭证与权限
- **第二十一条 ~ 第三十条** — 流程执行（结果导向、预判边界、自主恢复、幂等性检查等）
- **第三十一条 ~ 第三十三条** — 风险提醒与用户决策
- **第三十四条 ~ 第三十八条** — 数据保护与反馈

## 使用方式

将 `SKILL.md` 作为 Skill 加载到你的 Agent 系统中即可。支持 `triggers: 始终生效`，在 Agent 执行任何可能影响外部状态的操作前自动加载。
